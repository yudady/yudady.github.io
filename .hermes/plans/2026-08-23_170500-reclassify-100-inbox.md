# 100-InBox 重新分类（单层资料夹）实施计划

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 把 `docs/100-InBox` 下 222 个散乱档案按内容重新归类到一层资料夹（无嵌套），消除 AI / AI-WORKFLOW / Hermes / other 四个旧资料夹与 3 个根目录散档。

**Architecture:** 先对 222 个档案逐一读 frontmatter tags 做内容分类（纯文本处理，零风险）；再用 `git mv` 在 git 仓库内移动（可回滚）；移动后全库校验 wikilink 引用与资料夹层级；最后提交。图片附件跟随其宿主笔记。

**Tech Stack:** bash + python（frontmatter tag 解析）、git mv、Obsidian vault（`.obsidian` 存在于 docs/，是 Obsidian 库根）。

## 新分类方案（一层，7 个资料夹）

按内容主题划分，与库内既有顶层目录（200-學習OB / 300-閱讀筆記 / 600-developer 等）不冲突：

| 新资料夹 | 主题 | 预计数量 |
|---|---|---|
| `AI-Agent` | Agent 架构/工作流/多智能体/MCP/Skills/记忆系统（原 AI-WORKFLOW 全部 + AI 内同主题） | ~90 |
| `AI-Models` | 模型发布/评测/榜单（Claude/Gemini/Qwen/MiniMax/Gemma/DS-4 等） | ~20 |
| `Local-LLM` | 本地推理/部署/硬件（MLX、Ollama、llama.cpp、TinyGPU、本地模型部署） | ~15 |
| `Hermes` | 保留。Hermes Agent 全部相关（含原 AI/ 内散落的 Hermes 笔记合并进来） | ~45 |
| `AI-Tools` | 具体工具/开源项目介绍（OpenClaw、Goose、Multica、Flowise、MoneyPrinterTurbo 等） | ~30 |
| `NotebookLM` | NotebookLM 相关（PDF 导出、联动工作流、notebooklm-py） | ~8 |
| `misc` | 无法归入上述主题的杂项（原 other/ 内容 + 整理書籤等老笔记） | ~10 |

判定规则（按顺序）：
1. frontmatter 含 `hermes` tag 或标题以 "Hermes" 开头 → `Hermes`
2. 含 `ai-agent`/`agentic`/`workflow`/`mcp`/`skill` tag 或标题含 Agent/Loop/Skill/MCP/工作流 → `AI-Agent`
3. 含 `local`/`mlx`/`ollama`/`llama.cpp`/`本地` → `Local-LLM`
4. 含模型名（Claude/Gemini/GPT/Qwen/MiniMax/Gemma/DeepSeek/QN/Grok/DS-4/Llama）且主题是发布/评测 → `AI-Models`
5. 具体工具/项目名 → `AI-Tools`
6. NotebookLM 相关 → `NotebookLM`
7. 兜底 → `misc`

例外：`整理書籤.md`（2022 年老笔记）→ `misc`。

### Task 1: 生成分类 manifest

**Objective:** 对 222 个档案产出 machine-readable 的 filename → 新资料夹映射。

**Files:**
- Create: `.hermes/plans/reclassify-manifest.json`（工作产物，不入库）

**Step 1: 写分类脚本**

```python
#!/usr/bin/env python3
# save as /tmp/classify_inbox.py
import os, re, json, pathlib

ROOT = "/Users/tommy/Documents/work.nosync/yudady/yudady.github.io/docs/100-InBox"
OUT  = "/Users/tommy/Documents/work.nosync/yudady.github.io/.hermes/plans/reclassify-manifest.json"

MODEL_WORDS = ["Claude", "Gemini", "GPT", "Qwen", "MiniMax", "Gemma", "DeepSeek",
               "QN 3.6", "Grok", "DS-4", "Llama", "Mythos", "Fable"]
LOCAL_WORDS = ["MLX", "Ollama", "llama.cpp", "TinyGPU", "本地", "Local", "Rapid-MLX",
               "TurboQuant", "本地部署", "本地推理", "Thunderbolt"]
AGENT_WORDS = ["Agent", "Loop", "Skill", "MCP", "工作流", "Workflow", "Multi-Agent",
               "Kanban", "agentic", "Agentic", "记忆系统", "Memory", "Prompt", "提示词"]
TOOL_WORDS  = ["OpenClaw", "Goose", "Multica", "Flowise", "MoneyPrinterTurbo",
               "EasyVideoTrans", "VoxCPM", "PicoClaw", "OpenCode", "Cline", "Cursor",
               "FinceptTerminal", "FreeLLMAPI", "GitNexus", "GBrain", "Graphify"]

def classify(name: str, body: str) -> str:
    t = name + " " + body[:2000]
    if "Hermes" in name or "hermes" in body[:500]:
        return "Hermes"
    if "NotebookLM" in name or "NotebookLM" in body[:500]:
        return "NotebookLM"
    if any(w in t for w in LOCAL_WORDS):
        return "Local-LLM"
    if any(w in t for w in MODEL_WORDS):
        return "AI-Models"
    if any(w in t for w in TOOL_WORDS):
        return "AI-Tools"
    if any(w in t for w in AGENT_WORDS):
        return "AI-Agent"
    return "misc"

manifest = {}
for dirpath, dirnames, filenames in os.walk(ROOT):
    dirnames[:] = [d for d in dirnames if d != ".obsidian"]
    for fn in filenames:
        if fn == ".DS_Store":
            continue
        p = pathlib.Path(dirpath) / fn
        rel = str(p.relative_to(ROOT))
        try:
            body = p.read_text(encoding="utf-8", errors="ignore")
        except Exception:
            body = ""
        manifest[rel] = classify(fn, body)

with open(OUT, "w", encoding="utf-8") as f:
    json.dump(manifest, f, ensure_ascii=False, indent=2)

from collections import Counter
print(json.dumps(Counter(manifest.values()), indent=2))
print("total:", len(manifest))
```

# save as /tmp/move_inbox.sh
set -euo pipefail

ROOT = "/Users/tommy/Documents/work.nosync/yudady/yudady.github.io/docs/100-InBox"
os.chdir(ROOT)
mv = 0
for rel, dest in sorted(manifest.items()):
    if not os.path.exists(rel):
        print(f"WARN missing: {rel}"); continue
    subprocess.run(["git", "mv", rel, dest + "/"], check=True)
    mv += 1
print(f"moved: {mv}")

### Task 4: 校验 wikilink 引用完整性

**Objective:** 确认移动后库内 wikilink 不断链。

**Step 1: 写校验脚本**

```python
#!/usr/bin/env python3
# save as /tmp/check_links.py
import os, re, pathlib
VAULT = "/Users/tommy/Documents/work.nosync/yudady/yudady.github.io/docs"
wikilinks = re.compile(r"\[\[([^\]|#]+)")
notes = {}
for dp, dns, fns in os.walk(VAULT):
    dns[:] = [d for d in dns if d != ".obsidian"]
    for fn in fns:
        if fn.endswith(".md"):
            notes[fn[:-3]] = os.path.join(dp, fn)
broken = []
for name, path in notes.items():
    text = pathlib.Path(path).read_text(encoding="utf-8", errors="ignore")
    for m in wikilinks.finditer(text):
        target = m.group(1).strip()
        if target and target not in notes:
            broken.append((os.path.basename(path), target))
print("broken:", len(broken))
for b in broken[:20]:
    print(b)
```

**Step 2: 运行（移动前后各跑一次，对比）**

Run: `python3 /tmp/check_links.py`
Expected: 移动前后 broken 数量一致（wikilink 只认档名，`git mv` 不改档名 → 引用不受影响；此步是回归确认）。若数量增加 → 检查是否有非 wikilink 的相对路径图片引用（`![](images/...)`）并修正。
