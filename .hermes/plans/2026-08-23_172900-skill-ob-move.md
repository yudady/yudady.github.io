# ob-move — Obsidian 档案归档

把一个源资料夹（收件箱、旧结构目录）的档案按主题批量归档进目标分类资料夹。全程 git mv 可回滚。验收铁律：**wikilink/embed 断链 pre/post 同口径零增量**。

## 何时使用

- 「把 X 资料夹的 ob 档案移到 Y 分类资料夹」
- InBox / 001-TODO 定期清空归档
- 旧目录结构重组（多资料夹合并为一层）

## 核心约束

1. 不破坏目标结构：一层资料夹保持一层，不建新子目录（除非用户明说）
2. 移动只用 `git mv`（保留历史、可 revert）；最终验证通过前不 commit、永不自动 push
3. 断链零增量是硬验收——不是"看起来没断"，是同口径脚本 pre/post 对比相等
4. `.gitkeep` / 收件箱语义：源若是收件箱，清空后保留资料夹与 .gitkeep

## 流程（六步，每步一个动作）

### Step 1: 探查（只读）

```bash
# 源目录清单 + 子目录
find <SRC> -type f ! -name ".DS_Store" ! -name ".gitkeep" | sort
find <SRC> -type d
# git 必须干净（涉案两目录）
git status --porcelain -- <SRC> <DST>
```

frontmatter tags 采集（分类判定依据）：

```python
import os, pathlib, re
for dp, dns, fns in os.walk(SRC):
    dns[:] = sorted(d for d in dns if d != ".obsidian")
    for fn in sorted(fns):
        if fn in (".DS_Store", ".gitkeep"): continue
        p = pathlib.Path(dp, fn)
        tags = ""
        if fn.endswith((".md", ".html")):
            head = p.read_text(encoding="utf-8", errors="ignore")[:600]
            m = re.search(r"^tags:\s*(.+)$", head, re.M)
            if m: tags = m.group(1).strip()[:90]
        print(f"{p.relative_to(SRC)}|{tags}")
```

档名冲突检测（源 vs 目标全量 basename，必须为 0 才继续）：

```python
existing = {f.name for f in DST.rglob("*") if f.is_file()}
```

### Step 2: 判定 + manifest

- 逐档人工判定分类（tags + 标题 + 规则顺序），不搞关键词全自动——边界案例靠判断
- manifest 写 `<repo>/.hermes/plans/<slug>-manifest.json`，格式 `{"源相对路径": "目标资料夹名"}`
- 落盘脚本必须断言（缺一不可）：
  1. 目标值 ∈ 合法资料夹集合
  2. 磁盘档集合 ↔ manifest 键集合双向 diff 为空
  3. 无 (目标, basename) 冲突
  4. 分布计数与预期一致
- **繁简字陷阱**：断言报 missing 时，用 `[hex(ord(c)) for c in name]` 对比磁盘真名——手打键常差一个字（燈/灯）。修法：从磁盘名直接替换 manifest 键

### Step 3: 实施（子代理或自跑）

1. baseline：源档数、`git rev-parse HEAD`、link 脚本 pre 值（脚本见文末）
2. 逐条 `git mv <SRC>/<rel> <DST>/<dest>/`——python subprocess 列表传参，禁 shell 字符串拼接（档名含中文/空格/括号）
3. 空子目录 `rmdir`（只删空的；非空 = 有遗漏，停下报告）
4. 校验六项（输出原文留证）：
   - a. 源清空（.gitkeep 除外）；b. 源无子目录
   - c. 目标总数 = 原数 + 移动数；结构不破坏（层数、无根散档）
   - d. link 脚本 post 值 == pre 值（同口径）
   - e. 档名守恒：移动前后 basename 集合 diff 为空
   - f. `git -c core.quotepath=false status --porcelain -- <SRC> <DST>` 只有 R

### Step 4: Spec review 子代理（只读）

独立复验，不信实施者自报：
- manifest 逐条按 basename 验证落位（mismatch = 0）
- 反向核对：目标当前档名集 − `git ls-tree HEAD` 档名集 = manifest basename 集
- `diff --cached --name-status` 全 R100、.gitkeep 不在 diff 中
- 结构五项（总数/顶层资料夹数/无二层/无散档）

### Step 5: Quality review 子代理（只读）

针对性核查（按历史事故定向）：
1. **附件 embed 断链（头号雷）**：`git archive HEAD` 导出 pre 树，同尺对比 pre/post 的 wiki/embed/mdimg 断链——按链接文本对齐验多重集相等（宿主路径迁移会产生成对 new/gone，属正常）
2. **移动档内部 embed 扫描**：`![[images/...]]` 等相对前缀引用扁平化后必断 → 修法：改裸档名 `![[x.png]]`
3. rename 质量：全 R100
4. 兜底资料夹（misc）抽查：新增档是否符合非主题定位
5. 收件箱完整性：.gitkeep 在且被追踪
6. 副作用：全仓库 porcelain 除 R + workspace.json（Obsidian 自动写入，预期）+ .hermes/（未追踪，预期）外无变化

### Step 6: 修复循环 + commit

- review 有 Critical/Important → 修复子代理 → 控制器同尺复审（断链回到基线才算修完）
- commit 前 `git checkout -- docs/.obsidian/workspace.json`（丢弃 UI 噪音）
- commit 只 add 涉案目录；汇报新分布 + revert 指引；不 push（用户决定）

## Pitfalls（两轮实战踩过的坑）

1. **附件前缀断链**：`![[images/x.png]]` 移动扁平化后断。修法二选一：图片跟宿主同目录 + 引用改裸档名（最稳）；或建 images/ 子目录（违反一层约束时不用）
2. **同名目录 no-op**：`git mv Hermes/x.md Hermes/` 报 "can not move directory into itself"——该批档本就在目标位，程序化核实「no-op 数 + moved 数 = 总数」即可，不是错误
3. **Apple Git quotepath**：中文档名输出 `\350\241...` 转义，grep/sed 产生假差异。一律加 `-c core.quotepath=false`
4. **单目录 status 拆 rename**：`git status -- <仅目标目录>` 把 rename 拆显示为 D——源和目标都要在 scope 内才是 R
5. **繁简字**：manifest 键必须来自磁盘采集；手打差一个字（燈/灯）会断言失败——断言就是安全网，别绕过
6. **workspace.json 噪音**：Obsidian 运行时自动写入，commit 前 checkout 掉，别提交
7. **档名带 " 1" 副本**：如 `youtube-thumb-xxx 1.jpg` 常是重复下载；确认无引用后归兜底夹即可
8. **附件跟随规则**：图片的目标资料夹 = 引用它的宿主笔记的目标（先定宿主，附件随行）

## link 检查脚本模板（pre/post 各跑一次，对比 JSON）

```python
import os, re, pathlib, sys, urllib.parse, json
VAULT = "<vault 根，如 /path/docs>"
out_json = sys.argv[1]
wikilinks = re.compile(r"\[\[([^\]|#]+)")
md_embeds = re.compile(r"!\[\[([^\]|]+)")
files = {}
for dp, dns, fns in os.walk(VAULT):
    dns[:] = [d for d in dns if d != ".obsidian"]
    for fn in fns:
        if fn != ".DS_Store":
            p = pathlib.Path(dp, fn)
            files[urllib.parse.unquote(p.name)] = p
notes = {k: v for k, v in files.items() if k.endswith(".md")}
wiki_broken, embed_broken = [], []
for name, path in notes.items():
    text = path.read_text(encoding="utf-8", errors="ignore")
    for m in wikilinks.finditer(text):
        t = urllib.parse.unquote(m.group(1).strip())
        if t and t not in notes:
            wiki_broken.append((str(path.relative_to(VAULT)), m.group(0)))
    for m in md_embeds.finditer(text):
        t = urllib.parse.unquote(m.group(1).strip())
        if t and t not in files:
            embed_broken.append((str(path.relative_to(VAULT)), m.group(0)))
json.dump({"wiki_broken": wiki_broken, "embeds_broken": embed_broken},
          open(out_json, "w"), ensure_ascii=False, indent=1)
print(f"wiki broken: {len(wiki_broken)} | embeds broken: {len(embed_broken)}")
```

注意：绝对断链数无意义（vault 存量断链几百条），只有 **pre/post 同口径差值** 才是验收依据。
