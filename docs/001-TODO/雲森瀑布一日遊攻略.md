# 三峽雲森瀑布一日遊完整攻略 — 早午餐 + 秘境瀑布健行

```
  三峽市區                    熊空產業道路              雲森瀑布步道

 └──────────┘                 └──────────┘                └──────────┘

      │                                                        │
```

**核心路線**：三鶯交流道 → 三峽市區（清琳咖啡）→ 台七乙線 → 熊空 → 產業道路 → 雲森瀑布步道入口 → 健行 → 雲森瀑布

**難度評估**：

| 項目 | 評級 | 說明 |
|------|------|------|
| 步道難度 | ★★☆☆☆ | 低難度，但中後段有窄路與過溪 |
| 體力需求 | ★★☆☆☆ | 單程 40 分鐘，海拔落差約 170m |
| 駕駛難度 | ★★★★☆ | 產業道路極窄、會車困難 |
| 整體推薦 | ★★★★☆ | 適合全家出遊、夏季避暑 |

> [!info] 步道數據（健行筆記 + 多源交叉）
> - **距離**：單程約 2.1km，往返約 4.2km
> - **時間**：單程約 40-45 分鐘（往返約 80-90 分鐘）
> - **海拔落差**：約 170 公尺
> - **類型**：折返式步道（非環狀）
> - **遮蔭**：全程林蔭，正午也不曝曬

## 交通攻略

### 三種交通方式比較

| 方式 | 從三峽市區出發 | 便利度 | 停車 | 備註 |
|------|---------------|--------|------|------|
| 汽車 | 約 25 分鐘 | ★★☆☆☆ | 步道入口少量 / 登山口前100m有停車場（10-20台） | 產業道路極窄，會車壓力大 |
| 機車 | 約 25 分鐘 | ★★★★★ | 直接停步道入口 | 影片評語：「方便性第一名當之無愧」 |
| 公車 807 | 熊空站下車 | ★★★☆☆ | 不需停車 | 下車後步行 1.5km 約 30 分鐘到步道入口 |

### 開車路線（國道三號）

```
國道三號（三峽交流道）
    │
    ├─→ 三鶯交流道下（往三峽市區方向）
    │
    ▼
三峽市區（復興路）→ 清琳咖啡 QM159（三峽國小停車場對面）
    │
    ▼ 左轉台三線 → 左行大埔路 → 接台七乙線（往滿月圓方向）
    │
    ▼ 過五寮尖登山口 → 續行約 3.5km → 過湊合橋
    │
    ▼ 右行接北114鄉道 → 直行東峰橋 → 經熊空候車亭
    │
    ▼ 產業道路（注意：「道路狹小 會車不易」告示牌）
    │
    ├─→ 步道入口（少量車位）
    └─→ 登山口前 100m 停車場（10-20台，推薦）
```

### 產業道路會車實戰建議

影片實測，產業道路有以下特徵：

- **路幅極窄**：夾在山壁與護欄之間，僅容一車通過
- **避讓空間有限**：沿途偶有路邊加寬處可避讓對向來車
- **精神消耗大**：影片形容「精神緊繃如履薄冰」

> [!warning] 駕駛建議
> - **假日強烈建議騎機車** — 可直接停步道入口，免去會車壓力
> - 若必須開車，善用路邊避讓空間，遇到對向來車主動退讓
> - 停車選登山口前 100m 大停車場，步行上去僅約 2 分鐘
> - 機車可直達步道入口停車

## 雲森瀑布步道詳解

### 步道分段解析

```
步道入口
  │
  │ ▼ 前段（0-20min）— 平緩林蔭
  │   全程樹蔭遮蔽，路況平坦好走
  │   陸續出現階梯增添趣味
  │   有防止跌落的防護設施
  │
  ├──── 第一段階梯群
  │
  │ ▼ 中段（20-35min）— 地形變化
  │   高低起伏、上坡下坡
  │   巨木倒塌後被撐起橫跨路中
  │   沿途有穩固鋼構簡易橋
  │   狹窄崖邊路段（需小心！）
  │
  ├──── 輕便橋 / 過溪處
  │
  │ ▼ 後段（35-40min）— 接近瀑布
  │   開始聽到水流聲
  │   路幅超窄，需避讓對向山友
  │   踩石過溪（水位不高）
  │   鋼構橋（安全穩固）
  │
  ├──── 叉路口
  │   │
  │   ├─→ 左轉上山：森山瀑布（影片未走）
  │   │
  │   └─→ 直走：雲森瀑布 ← 目標
  │
  ▼
雲森瀑布（攀過大石到達瀑布底端）
```

### 步道安全重點

> [!danger] 需要特別小心的路段
> 1. **狹窄崖邊路**（7:00-7:25）— 中後段有崖邊窄路，一暈一軟就可能掉落山谷，**必須結伴同行**
> 2. **過溪處**（9:30-9:56）— 需踩石過溪，水位不高但石頭濕滑，建議穿防滑/防水鞋
> 3. **超窄路幅**（7:53）— 接近瀑布處路幅極窄，需避讓對向山友

### 步道特色總結

| 特色 | 詳情 |
|------|------|
| 全程遮蔭 | 樹蔭密布，正午一點也不怕太陽曬 |
| 前段平坦 | 好走但略顯無聊，有階梯增添樂趣 |
| 後段精彩 | 高低起伏、溪谷、獨木橋、鋼構橋，一點都不無聊 |
| 水源豐富 | 多處過溪、聽到水流聲就知道瀑布近了 |
| 負離子 | 瀑布區水氣充沛，負離子滿載 |

## 瀑布景致與安全須知

### 雲森瀑布小知識

- **原名**：「雲心瀑布」，與上方一層的「森山瀑布」合稱「雲森瀑布」
- **現況**：眼前這道瀑布現統稱「雲森瀑布」
- **步道沿線另有**：阿花瀑布（單程約 3km、步行約 1 小時可見三座瀑布）

### 瀑布觀賞體驗

攀過大石即可直達瀑布底端：

- **水氣充沛**：一上去就感受到清涼水氣撲面而來
- **負離子滿載**：有益健康的森林浴
- **層次分明**：水量充沛、岩石段落有層次，壯觀又美
- **景觀佳**：轉身向下看的溪谷景觀也很不錯

> [!note] 影片花絮
> 瀑布區遇到一位帶著黑狗「妞妞」的阿伯。阿伯說妞妞小時候曾被虎頭蜂咬過，所以現在看到蜜蜂就會去咬牠。影片的溫馨插曲。

## 裝備清單

> [!check] 必備裝備
> - [ ] 防滑/防水鞋款（過溪踩石用）
> - [ ] 充足飲水（來回 80 分鐘 + 高低起伏）
> - [ ] 輕便背包
> - [ ] 防蚊液（森林步道蚊蟲多）

> [!tip] 建議裝備
> - [ ] 登山杖（後段下坡路段輔助）
> - [ ] 帽子（雖然全程遮蔭，但仍有用）
> - [ ] 簡單行動糧/零食
> - [ ] 手機/相機（瀑布拍照）
> - [ ] 毛巾/替換衣物（過溪可能弄濕）

> [!warning] 不建議
> - [ ] 涼鞋/拖鞋（過溪石頭滑，不安全）
> - [ ] 獨自前往（後段有崖邊窄路）
> - [ ] 雨天前往（溪水暴漲風險）
