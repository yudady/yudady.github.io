## 概览

OpenAI Codex 桌面 APP 保姆级教程，从安装到进阶。一个 ChatGPT 账号（Plus $20/月 推荐）即可使用，支持 macOS 和 Windows。

## 基础功能

### 1. 对话 + 文件操作
- 选择本地文件夹作为工作空间，AI 在范围内读写文件
- 三种权限模式：默认（需确认）、自动审查（推荐新手）、完全访问
- 实测：扫描大文件、清理预览文件，成功节省 6.8GB 空间

### 2. 完整网站开发（计划模式）
- 切换工作模式为"编程"，选择 GPT-5.5 + 高智能
- **计划模式**（左下角 + 号开启）：AI 先规划方案再动手，生成实现计划文档（简介、核心要求、测试计划）
- AI 自动生图（内置图像生成技能）→ 编写代码 → 自主浏览器测试 → 7 分钟完成整个任务
- **浏览器批注修改**：点击右上角批注按钮，选中页面元素写修改意见，AI 自动定位代码精准修改
- 额度查看：左下角设置 → 剩余额度，按 5 小时 + 一周限制

## 核心功能

### 3. 插件系统 + Netlify 部署
- 内置插件市场：Computer Use、Chrome 操控、表格处理、PPT、GitHub 等
- @插件名 调用，一句话部署网站到 Netlify（免费托管）

### 4. Browser Use（浏览器自动化）
- 设置 → 浏览器 → 开启 Browser Use
- @浏览器 调用，AI 自动打开网页、导航、截图、填表单
- 不太稳定，多试几次
- **Chrome 扩展**：操控已登录的 Chrome，保留登录状态，后台执行，适合需要登录的操作

### 5. Computer Use（操控整台电脑）
- 设置 → 电脑操控 → 安装插件
- @电脑 调用，AI 能截屏、移动鼠标、点击、打字、操作任何桌面应用
- 仅支持 macOS，操作效率偏低，很烧 tokens（一个任务可能用近 8 万上下文）
- 建议：能用终端命令和浏览器完成的操作就不要用 Computer Use

### 6. Skills（技能包）
- 按需加载的技能文件，任务匹配时自动调用，不浪费上下文
- **内置技能**：图片生成、官方文档查询、技能安装器、技能创建器
- **社区技能**：Firecrawl（联网搜索）、Context7（最新技术文档）、UI/UX Pro Max（前端美化）
- `$技能名` 快速调用
- **自定义技能**：本质是 SKILL.MD 描述文件 + 配套脚本，用内置 Skill Creator 一键生成
- 安全提示：知名技能直接安装，不太知名的给 GitHub 链接让 Codex 检查后安装

### 7. MCP（外部服务连接）
- AI 万能插头，连接外部工具和数据源
- 设置 → MCP 服务器，需手动填写配置（对新手不友好）
- 主流扩展提供快捷安装命令（如 Context7 一行命令安装）
- 推荐用于需要实时技术文档的开发场景

## 进阶功能

### 8. 上下文管理
- GPT-5.5 有效上下文约 **258K tokens**，不算多
- `/压缩` 斜杠命令主动压缩历史对话
- 对话归档：左侧列表归档旧对话，保持界面清爽

### 9. 记忆机制（三层）
- **全局记忆**：设置 → 个性化，写入 AGENTS.MD（所有项目通用）
- **项目记忆**：项目根目录 AGENTS.MD（项目专属规则，可让 AI 自动生成）
- **自动记忆**：后台自动总结有用信息，额度快用完时不触发

### 10. 定时自动化任务
- 自动化面板 → 内置模板（代码变更总结、代码检查等）
- 两种创建方式：面板新建（填名称/提示词/触发时间）或让 AI 帮你创建
- 实例：每日搜集热点、自动整理图片文件名、每周生成周报 PPT

### 11. 桌面宠物
- 设置 → 外观 → 宠物，内置像素风赛博宠物
- 实时反映 Codex 工作状态（AI 忙时宠物也在干活）
- 社区库 PetDex 2000+ 只玩家自制宠物
- Hatch Pet 技能：上传照片或文字描述自定义生成

### 12. Git 版本管理
- 侧边栏审核面板：查看所有改动文件，灵活暂存/还原
- 代码块级别控制：每个改动拆分为多个块，逐块决定保留/丢弃
- 内置提交、推送到远程、创建 PR

### 13. 工作树模式
- 创建新对话时选择"新工作树"，AI 在隔离分支工作
- 适合多个 Agent 并行在同一项目上干活，减少冲突

### 14. 手机远程控制
- 设置 → Codex 移动版 → 二维码 → 手机 ChatGPT APP 扫码
- 随时随地给电脑上的 Codex 下达任务、审批操作、查看进度

## 关键数据
- GPT-5.5 有效上下文：约 258K tokens
- Computer Use 单任务可能消耗近 8 万上下文
- Plus 额度：按 5 小时 + 一周限制，日常足够
