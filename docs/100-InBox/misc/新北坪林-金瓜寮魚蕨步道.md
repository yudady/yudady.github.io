# 新北坪林金瓜寮魚蕨步道 — 機車一日遊攻略（新庄出發）

> 位於新北市坪林區的金瓜寮魚蕨步道，是北勢溪上游支流「金瓜寮溪」沿線的親水森林步道。因長年封溪護魚與水源保護，溪水清澈見底、台灣原生魚成群，配合茂密森林遮蔭，被譽為北台灣夏季最佳避暑勝地之一。步道分為兩段，平緩好走、出入口彈性高，對親子與健行初學者非常友善。

## 一、路線基本概況與交通建議

### 1.1 路線數據一覽

| 項目 | 數據 |
|------|------|
| 步道全長（兩段合計） | 約 2.2 公里 |
| 環狀總里程（含產業道路） | 約 4.3 公里 |
| 海拔範圍 | 269～330 公尺 |
| 累計爬升 | 124m |
| 累計下降 | 114m |
| 預估時間 | 約 2.5 小時 |
| 難度 | 低（平緩好走） |

### 1.2 步道分段結構

步道分為**第一段**與**第二段**，中間以產業道路（約 50 公尺）串接。第一段以森林景觀、蕨類生態為主；第二段緊貼溪岸，是全線精華（瀑布、月牙灣、猴橋、蕨類公寓）。

```
北入口 ──第一段(森林/拱橋/雙扇蕨)── 南出口
                                        │
                                   產業道路~50m
                                        │
        ┌──第二段(斷層瀑布/猴橋/月牙灣/蕨類公寓)──┘
        │
   1~7 號出入口（隨時可切出產業道路）
```

### 1.3 交通與停車

#### 開車 / 騎車

- **導航設定**：Google Maps 搜「金瓜寮觀魚步道北側出入口」或「金瓜寮魚蕨步道」
- **地址**：新北市坪林區金瓜寮路（無明確門牌）
- **北入口停車位少**：建議停放「北入口前方公車站旁空地」，再步行回起點
- **南入口**：路邊白線可停，但道路狹窄，停車不便
- **第二段入口**：白線可停車，旁有廁所與公車站牌
- **機車停車**：路邊均可停放，比汽車彈性大

#### 公車

- 捷運新店站搭乘 923 至坪林國中 → 轉乘新巴士 F722、F723 至「蕨類步道」下車

#### 重要提醒

- **手機訊號**：步道區幾乎無訊號，務必提前下載離線地圖（Google Maps 坪林區離線包）
- **廁所位置**：2 號出口旁設有公廁
- **GPX 軌跡檔**：創作者提供 Google Drive 下載
  `https://drive.google.com/drive/folders/1c0mZ6Ws_1ny0MOwcEROe6lS6zlodi3u4`

### 1.4 出入口彈性設計（1~7 號）

步道沿線設有 1 至 7 號多個出入口，皆可連接產業道路。體力有限或只走特定精華段的遊客，可隨時從任一號出口切出，不需走完全程。

| 適合人群 | 建議走法 |
|----------|----------|
| 親子 / 長輩 / 初學者 | 只走第二段精華（月牙灣、猴橋），從中段出口切入 |
| 健行愛好者 | 兩段全走 + 產業道路環狀，4.3K 完整體驗 |
| 時間有限 | 第一段走到拱橋觀魚即折返 |

## 二、景點核心特色與地理生態

### 2.1 地名由來與水源保護

**金瓜寮**地名由來：早年居民在此種植金瓜（南瓜），並搭建寮房看顧農作，因而得名「金瓜寮」。

**水源地位階**：

```
翡翠水庫（大台北飲用水源）
   ↑
北勢溪（翡翠水庫上游）
   ↑
金瓜寮溪（北勢溪重要支流） ← 步道沿線
```

因處於翡翠水庫集水區，金瓜寮溪長年實施**封溪護魚**與**水源保護**，才能保有如此清澈的溪流與完整生態。這也是步道名稱「魚蕨」的由來——魚（原生魚類）與蕨（蕨類植物）是兩大生態亮點。

### 2.2 第一段步道：森林景觀與古老植物

#### 拱橋（地標）

步道最具代表性的地標。跨越溪流，是俯瞰清澈溪水與觀察魚群的最佳位置。橋中央可停下腳步感受溪流與森林交織的自然美景。

**觀魚亮點**：金瓜寮溪生活著多種台灣原生魚——
- 台灣馬口魚（常見）
- 苦花魚
- 石賓（石賓魚）

> 這些魚類對水質要求極高，牠們的存在本身就是金瓜寮溪水質良好的最佳證明。

#### 芒萁（古老蕨類）

路旁常見的蕨類植物。早期農村會將其葉柄綁成一束，做成天然的鍋刷/碗刷（刮刷），用來刷鍋洗碗。同時也是森林演替的**先鋒植物**——最早在裸露地生長、為後續植物打底。

#### 雙扇蕨（活化石）

| 項目 | 說明 |
|------|------|
| 歷史 | 兩億多年，被稱為「活化石」 |
| 外觀特徵 | 葉片形狀特殊，有「破雨傘」之稱 |
| 文化地位 | **淡蘭古道沿線代表植物**，被選為淡蘭古道 Logo |
| 象徵意義 | 代表百年山徑豐富的自然生態與悠久歷史 |

### 2.3 第二段步道：精華水岸與地質景觀

第二段緊貼金瓜寮溪岸，是許多人認為最精彩的一段。沿途景點密集：

#### 台灣沙欏（公主）

樹幹基部包覆著枯葉，如裙擺般垂下，被形象化稱為「公主」。樹狀蕨類，見證溪谷潮濕溫暖的微氣候。

#### 斷層瀑布

| 項目 | 說明 |
|------|------|
| 特色 | **非以高度見長** |
| 成因 | 地殼運動造成岩層產生高低落差 |
| 景觀 | 溪水順著岩盤流下，形成特殊地質景觀 |
| 類型 | 地質型瀑布（非水量型/落差型） |

#### 猴橋

早年這裡沒有真正的橋，而是天然樹木橫跨溪流形成「天然樹橋」。據說猴子會沿樹幹穿越溪谷，居民因而稱此地為「猴橋」。後來興建正式橋樑後，仍沿用此名。

#### 月牙灣（全線人氣王）

溪流在此形成彎月形河道，因而得名。溪水清澈、水流平緩，是**全線最受歡迎的泡腳、戲水和拍照點**。

```
        ╭─────────╮
       ╱           ╲      ← 月牙形河道
      │   平緩清澈   │         水流慢、適合親水
       ╲           ╱
        ╰─────────╯
```

#### 蕨類公寓

一棵大樹上長滿了各種附生蕨類，看起來就像許多住戶住在同一棟公寓，因而得名。代表此處擁有非常良好的森林環境與高濕度微氣候，是溪谷生態多樣性的縮影。

## 三、行前準備與實用建議

> 步道部分與機車行程適用，以下分為「步道裝備」與「機車騎乘」兩類。

### 3.1 步道狀況警告

- **青苔濕滑**：部分木棧道、大石塊因潮濕長有青苔，須格外注意防滑
- **樹根交錯**：部分路段樹根裸露交錯，行走時留意腳下
- **陡坡路段**：第一段末段有超陡坡（影片 07:04 標記），需小心

### 3.2 裝備建議

| 裝備 | 建議 | 原因 |
|------|------|------|
| 鞋款 | 抓地力佳的登山鞋 / 溪陸兩用鞋 | 青苔濕滑、樹根路段 |
| 衣物 | 簡便親水衣物 + 替換衣物 | 月牙灣可泡腳戲水 |
| 防曬 | 輕量防曬 | 林蔭遮蔽度高，需求低 |
| 飲水 | 基本量即可 | 步道短、遮蔭多 |

### 3.3 避暑體驗

步道兩側高大樹木遮蔽形成天然樹蔭，配合溪流帶走熱氣，**體感溫度比市區低許多**。夏季走來如天然冷氣房，是北台灣絕佳的避暑選擇。

### 3.4 機車騎乘裝備與準備

| 裝備 | 建議 | 原因 |
|------|------|------|
| 安全帽 | 全罩式 | 北宜公路彎多，安全第一 |
| 手套 | 車用手套 | 長時間騎乘保護手部 |
| 防摔衣 | 有護具的防摔外套 | 山路摔車風險較高 |
| 雨衣 | 薄雨衣隨身 | 山區午後易變天 |
| 油箱 | 出發前加滿 | 北宜公路途中無加油站，坪林市區有中油 |
| 防曬 | 防曬乳 + 薄外套 | 山區溫差大 |

## 四、機車一日遊行程（新庄出發）

### 4.1 路線總覽

```
新庄 →（台64線）→ 新店 →（台9線北宜公路）→ 坪林 →（金瓜寮路）→ 金瓜寮魚蕨步道
                                                                ↓
                         坪林美食 → 茶業博物館 → 原路返航（或走106乙線）
```

| 項目 | 數據 |
|------|------|
| 單程距離 | 約 50 公里 |
| 單程騎乘時間 | 約 1.5 小時（含市區紅綠燈） |
| 步道停留 | 2-3 小時 |
| 全天總時間 | 約 7-8 小時（含午餐、休息） |

### 4.2 路線分段說明

#### 第一段：新庄 → 新店（台9線起點）

- **路線**：新庄 → 板橋/中和 → 新店（走台64快速道路或一般道路）
- **車程**：約 30-40 分鐘
- 新店捷運站旁是傳統車友集合點

#### 第二段：新店 → 坪林（北宜公路 台9線）

- **全程**：約 30-35 公里
- **車程**：約 50-60 分鐘（限速40，彎多）
- **途經**：石碇 → 坪林
- **注意**：全程區間測速，速限 40km/h，多段執法中

#### 第三段：坪林市區 → 金瓜寮魚蕨步道

- 從坪林市區轉北宜路八段 → 過渡南橋 → 接金瓜寮路
- **車程**：約 10-15 分鐘
- **導航**：Google Maps 搜「金瓜寮觀魚步道北側出入口」

### 4.3 建議時間表

| 時間 | 行程 |
|------|------|
| 08:30 | 新庄出發 |
| 09:00 | 抵新店，上北宜公路 |
| 10:00 | 抵達坪林，休息 / 加油 |
| 10:30 | 騎至金瓜寮魚蕨步道 |
| 10:45 | 開始走步道（北口進） |
| 11:30 | 到南口，溪邊玩水休息 |
| 12:30 | 回到坪林市區吃午餐 |
| 14:00 | 茶業博物館 / 心茶合一下午茶 |
| 15:30 | 啟程返航 |
| 17:00 | 回到新庄 |

### 4.4 北宜公路騎乘注意事項（重要）

#### 區間測速執法路段（速限 40）

| 路段 | 里程 | 狀態 |
|------|------|------|
| 新店端 | 19K – 23.1K | 執法中 |
| 石碇往坪林 | 26.2K – 32.2K | 執法中 |
| 坪林段 | 33.3K – 37.2K | 2025/6/1 起雙向執法 |

#### 區間測速原理

區間測速算的是**通過整段路的平均速率**，不是瞬間車速。直線衝刺、進彎急煞完全沒用，只要整段平均超標就開單。

#### 其他騎乘提醒

- 彎道密集，對向有大車砂石車，**勿切西瓜壓雙黃線**
- 午後山區易起霧，雨天路面濕滑、彎角易有落葉青苔
- 財茂彎（32.8K）是追焦熱點，人多事故多，別為拍照硬壓
- 留三分餘裕，騎七分就好
- 假日車多，建議早上 8-9 黈出發避開車潮
- 盡量在下午 3-4 點前開始下山

### 4.5 替代路線：106乙線（回程推薦）

除了北宜公路（台9線），還有另一條路可走：

- **路線**：坪林 → 106乙線 → 石碇 → 深坑 → 新店 → 新庄
- **特點**：沿途茶園風光、彎道較少、路況輕鬆
- **注意**：近年同样新增區間測速
- **建議**：去程走北宜（台9）體驗經典路線，回程走 106乙 不同風景
- **順遊**：回程經深坑老街可吃臭豆腐

## 五、步道景點導覽（按步行順序）

> 以下為兩段步道沿途景點，按實際步行順序排列。時間為從北口出發的累計預估步行時間（不含長時間停留拍照）。

### 第一段步道（北口 → 南出口，約 1065m）

| 預估時間 | 景點 / 事件 | 說明 |
|----------|------------|------|
| 0 min | **北側入口出發** | 金瓜寮產業道路 5.5K 附近，留意急降階梯 |
| ~5 min | 路徑小腰繞 | 部分路段路況變化，繞行產業道路再接回山徑 |
| ~10 min | **拱橋**（地標、觀魚點） | 步道最具代表性建築，俯瞰溪水觀察魚群 |
| ~12 min | 溪邊戲水區 | 可近距離接觸溪水 |
| ~15 min | 觀蕨平台 | 解說蕨類生態的休憩點 |
| ~18 min | **芒萁**（古老蕨類） | 早期農村用來做天然鍋刷；森林先鋒植物 |
| ~22 min | **雙扇蕨**（活化石） | 兩億年歷史，淡蘭古道 Logo 植物 |
| ~25 min | 超陡坡路段 | 第一段最需注意的陡坡，小心下行 |
| ~30 min | **走出南出口** | 第一段結束 |

> 第一段步行約 30-50 分鐘（含休息、拍照約 1 小時）

### 產業道路銜接

| 預估時間 | 說明 |
|----------|------|
| ~3 min | 南出口 → 第二段入口，走金瓜寮產業道路約 50-100m |

### 第二段步道（入口 → 出口，約 1074m）

| 預估時間 | 景點 / 事件 | 說明 |
|----------|------------|------|
| ~35 min | 第二段入口出發 | 緊貼溪岸，風景更明媚 |
| ~40 min | **台灣沙欏**（公主） | 樹狀蕨類，枯葉如裙擺 |
| ~45 min | **斷層瀑布** | 第二段最大亮點，地質型瀑布，碧綠溪水 |
| ~52 min | **猴橋** | 獼猴利用樹木越溪的地點 |
| ~60 min | **月牙灣**（人氣王） | 彎月形河道，淺水區，最佳戲水拍照點 |
| ~70 min | **蕨類公寓** | 附生蕨類長滿大樹，生態多樣性縮影 |
| ~75 min | 第二段出口 | 步道全線結束 |

> 第二段步行約 40-50 分鐘（含休息、拍照約 1-1.5 小時）

## 七、行動建議

1. **步道路線規劃**：時間充足者建議完整走完一、二段（第一段賞森林蕨類、第二段賞瀑布月牙灣），回程經產業道路返回，體驗最完整
2. **步道裝備準備**：穿著抓地力佳、防滑的登山鞋或溪陸兩用鞋，並攜帶簡便親水/替換衣物
3. **停車與時間**：夏季避暑人潮較多，開車前往宜儘早抵達公車站旁停車，並隨時留意步道濕滑路段
4. **季節選擇**：夏季最佳（避暑 + 親水）；雨後避開（青苔更滑、溪水暴漲風險）
5. **機車出發前**：加滿油（北宜公路途中無加油站）、下載坪林區離線地圖（步道區無訊號）、全罩安全帽與手套
6. **北宜公路**：全程區間測速速限 40，算平均速率不是瞬間速，穩定巡航比急衝急煞重要
7. **時間掌控**：早上 8-9 點出發避開車潮，下午 3-4 點前下山避免午後起霧
8. **護魚規定**：金瓜寮溪為護魚區，禁止撈魚撈蝦，玩水可以但不能帶走任何生物
